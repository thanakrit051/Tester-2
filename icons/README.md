# ไอคอนของแอป

ทุกไฟล์ในโฟลเดอร์นี้ **สร้างขึ้นอัตโนมัติ** อย่าแก้ไฟล์ภาพโดยตรง

## ต้นฉบับ

`icon.svg` คือต้นทางเดียวของรูปทรง — ตัว A วาดด้วยเส้น (path) ล้วน ไม่ใช้ฟอนต์
จึงออกมาเหมือนกันทุกเครื่องทุกเบราว์เซอร์

สีล็อกกับระบบดีไซน์ใน `styles.css`

| ส่วน | ตัวแปรใน CSS | ค่า |
|---|---|---|
| พื้นไทล์ | `--lime` | `#c7f04a` |
| ตัว A | `--on-lime` | `#0b2b24` |

รูปทรงเดียวกับ `.brand` (ไทล์ A ในแถบหัว) และ `.boot-mark` (หน้าจอตอนเปิดแอป)
**แก้สีในดีไซน์เมื่อไหร่ ต้องแก้ที่ `icon.svg` + `tools/make-icons.ps1` แล้วสร้างใหม่ด้วย**

## สร้างใหม่

```powershell
powershell -ExecutionPolicy Bypass -File tools/make-icons.ps1
```

## ไฟล์ที่ได้ และใครใช้

| ไฟล์ | ขนาด | ใช้ที่ไหน |
|---|---|---|
| `favicon.ico` | 16+32+48 | แท็บเบราว์เซอร์ (รวมตัวเก่า) |
| `favicon-16/32/48.png` | | แท็บเบราว์เซอร์ · ต้นทางของ `.ico` |
| `icon.svg` | เวกเตอร์ | แท็บเบราว์เซอร์รุ่นใหม่ (คมทุกความละเอียด) |
| `apple-touch-icon.png` | 180 | iPhone/iPad ตอน "เพิ่มลงหน้าจอโฮม" — เต็มกรอบ ไม่มีมุมมน ไม่มีพื้นโปร่ง (iOS ใส่มุมมนเอง) |
| `icon-192.png` · `icon-512.png` | | `manifest.webmanifest` แบบ `any` — มุมมน พื้นโปร่ง |
| `icon-192-maskable.png` · `icon-512-maskable.png` | | `manifest.webmanifest` แบบ `maskable` — เต็มกรอบ ตัว A ย่อ 78% ให้อยู่ในวงกลมปลอดภัย 80% ตามข้อกำหนดของ Android |
| `og-image.png` | 1200×630 | ภาพตัวอย่างตอนแชร์ลิงก์ในไลน์/เฟซบุ๊ก |

`tools/build-pages.mjs` จะคัดลอกโฟลเดอร์นี้ไปไว้ที่ `docs/icons/` ให้เอง
เพราะหน้านักเรียนและฝั่ง Apps Script ดึงไฟล์จาก `docs/`
