# AssignCheck V2

ระบบ All-in-one สำหรับครู: **เช็คชื่อ · เช็คการส่งงาน · กรอกคะแนน → สรุปเป็น 8 ช่องพร้อมกรอกลง SGS**

- หน้าเว็บ: static ล้วน วางบน **GitHub Pages** ได้เลย (ไม่มี build step ไม่มี dependency)
- ฐานข้อมูล: **Google Sheet ไฟล์เดียว** — 1 ห้อง-วิชา = 1 แท็บ
- ตัวกลาง: **Google Apps Script Web App** ผูกกับ Sheet นั้น

```
[GitHub Pages · หน้าเว็บ]  ──POST──>  [Apps Script Web App]  ──>  [Google Sheet ไฟล์เดียว]
        ↕ localStorage (แคช + คิวงานออฟไลน์)
```

## 1. ติดตั้ง (ทำครั้งเดียว ~10 นาที)

### 1.1 ฝั่ง Google Sheet

1. สร้าง Google Sheet ใหม่ 1 ไฟล์ ตั้งชื่ออะไรก็ได้
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. เลือกโค้ดเดิมใน `Code.gs` ทั้งหมด (Ctrl+A) แล้ววางเนื้อหาของ
   **[`apps-script/ALL-IN-ONE.gs`](apps-script/ALL-IN-ONE.gs)** ทับลงไป — ไฟล์เดียวจบ

   > อยากแยกเป็น 5 ไฟล์ให้อ่านง่ายก็ได้ ใช้ `00_Constants.gs`, `01_Setup.gs`,
   > `02_ClassSheet.gs`, `03_Score.gs`, `04_Api.gs` แทน (ผลเหมือนกัน)
   >
   > แก้โค้ดต้นทางแล้วสร้าง ALL-IN-ONE ใหม่ด้วย `node tools/bundle.mjs`

4. กด **บันทึก** (Ctrl+S) → กลับไปที่ Sheet → **รีเฟรชหน้า** จะเห็นเมนู **📗 AssignCheck**
5. เมนู **📗 AssignCheck → 🚀 ติดตั้ง / ซ่อมแซมโครงสร้าง**
   → ระบบสร้างแท็บ `📖 วิธีใช้`, `🏫 ห้องเรียน`, `⚙️ ตั้งค่า` และสร้าง **รหัสลับ (API Key)** ให้
6. เปิดแท็บ `📖 วิธีใช้` แล้วคัดลอก **รหัสลับ** เก็บไว้

### 1.2 Deploy Web App

ใน Apps Script กด **Deploy → New deployment**

| ช่อง | ค่า |
|---|---|
| Select type | **Web app** |
| Execute as | **Me** |
| Who has access | **Anyone** |

กด Deploy → อนุญาตสิทธิ์ → คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

> **"Anyone" ปลอดภัยไหม?** ปลอดภัย เพราะทุกคำขอต้องแนบรหัสลับที่อยู่ในไฟล์ Sheet ของคุณเท่านั้น
> ถ้ารหัสหลุด ให้กดเมนู **🔑 สร้างรหัสลับใหม่** แล้วเชื่อมเว็บแอปใหม่

### 1.3 ฝั่งเว็บ (GitHub Pages)

1. push โฟลเดอร์นี้ขึ้น GitHub repo
2. Settings → Pages → Source: `Deploy from a branch` → branch `main` / folder `/ (root)`
3. เปิด URL ที่ได้ → กรอก **Web app URL** + **รหัสลับ** → กด **เชื่อมต่อ**

เสร็จแล้ว 🎉 (เพิ่มลงหน้าจอโฮมของมือถือได้ ใช้เป็นแอปเลย)

## 2. โครงสร้างข้อมูลใน Google Sheet

### แท็บระบบ

| แท็บ | ใช้ทำอะไร |
|---|---|
| `📖 วิธีใช้` | สรุปวิธีอ่านไฟล์ + รหัสลับ |
| `🏫 ห้องเรียน` | สารบัญห้อง/วิชาทั้งหมด (ระบบเขียนเอง — ห้ามแก้มือ) |
| `⚙️ ตั้งค่า` | น้ำหนักคะแนน กติกาเช็คชื่อ การปัดเศษ เกณฑ์เกรด |

### แท็บห้องเรียน (1 ห้อง-วิชา = 1 แท็บ)

ทุกอย่างของห้องนั้นอยู่ในแท็บเดียว ไล่จากซ้ายไปขวาเป็นบล็อกสี:

```
A     B          C              │ 🕐เช็คชื่อ ช1 │ 📝ส่งงาน ช1 │ ✍️สอบเก็บ ช1 │ 📄กลางภาค │ …ช2… │ 📊สรุป SGS
เลขที่ เลขประจำตัว ชื่อ-นามสกุล  │ ม ส ล ข     │ 0–เต็ม      │ 0–เต็ม       │ 0–เต็ม    │      │ 8 ช่อง + รวม + เกรด
```

| แถว | ใช้ทำอะไร |
|---|---|
| 1 | หัวเรื่อง |
| **2** | ข้อมูลระบบ (**ซ่อนไว้ อย่าลบ**) — `classId`, ชื่อวิชา, ชั้น, ห้อง… |
| 3 | หัวกลุ่มสี บอกว่าบล็อกนี้คืออะไร |
| **4** | รหัสคอลัมน์ `KIND\|HALF\|ID` (**ซ่อนไว้ อย่าลบ**) |
| 5 | ชื่อคอลัมน์ (วันที่-คาบ / ชื่องาน) |
| 6 | คะแนนเต็ม |
| 7+ | ข้อมูลนักเรียน |

**ค่าที่ใส่ได้ในเซลล์**

| บล็อก | ค่า |
|---|---|
| เช็คชื่อ | `ม` มา · `ส` สาย · `ล` ลา · `ข` ขาด · ว่าง = ยังไม่เช็ค |
| ส่งงาน / สอบ | `8` = ส่ง ได้ 8 · `L8` = **ส่งช้า** ได้ 8 · `x` = ไม่ส่ง (นับ 0) · ว่าง = ยังไม่ตรวจ |

**รายละเอียดงาน** เก็บเป็น *โน้ต* บนเซลล์ชื่อคอลัมน์ (แถว 5) — เอาเมาส์ชี้ที่หัวคอลัมน์ในชีตแล้วเห็น

ตรึงแถว 1–6 และคอลัมน์ A–C ไว้แล้ว เลื่อนดูได้สบาย · แก้ในชีตโดยตรงก็ได้ แค่กด **โหลดข้อมูลใหม่** ในแอป

## 3. วิธีคิดคะแนน

| ช่อง SGS | ถังคะแนน | เต็ม | ที่มา |
|---|---|---|---|
| 1 | ส่งงาน (ก่อนกลางภาค) | 10 | บล็อก 📝 ช่วง 1 |
| 2 | สอบเก็บคะแนน (ก่อนกลางภาค) | 10 | บล็อก ✍️ ช่วง 1 |
| 3 | เข้าเรียน (ก่อนกลางภาค) | 5 | บล็อก 🕐 ช่วง 1 |
| กลางภาค | สอบกลางภาค | 20 | บล็อก 📄 |
| 10 | ส่งงาน (หลังกลางภาค) | 10 | บล็อก 📝 ช่วง 2 |
| 11 | สอบเก็บคะแนน (หลังกลางภาค) | 10 | บล็อก ✍️ ช่วง 2 |
| 12 | เข้าเรียน (หลังกลางภาค) | 5 | บล็อก 🕐 ช่วง 2 |
| ปลายภาค | สอบปลายภาค | 30 | บล็อก 📕 |

**งาน / ข้อสอบ** — เทียบสัดส่วนอัตโนมัติ สั่งงานกี่ชิ้น เต็มเท่าไหร่ก็ได้:

```
คะแนน = น้ำหนัก × (ผลรวมคะแนนที่ได้) ÷ (ผลรวมคะแนนเต็ม)
```
- `x` (ไม่ส่ง) → นับเป็น 0 แต่ **นับ**ในตัวหาร
- ว่าง (ยังไม่ตรวจ) → ขึ้นกับ `ungraded_mode`: `ignore` ไม่นับในตัวหาร (ค่าเริ่มต้น) หรือ `zero` นับเป็น 0

**เข้าเรียน** — เลือกได้ 2 โหมดในหน้าตั้งค่า
- `ratio` : `5 × (Σ น้ำหนักสถานะ) ÷ จำนวนคาบที่เช็คแล้ว` (มา 1 · สาย 0.5 · ลา 1 · ขาด 0)
- `deduct` : `5 − (สาย×0.25 + ขาด×0.5)` ต่ำสุด 0

**ธงเตือนอัตโนมัติ**
- `มส` — เวลาเรียนต่ำกว่าเกณฑ์ (ค่าเริ่มต้น 80%)
- `ยังไม่ตรวจ n รายการ`
- `เสี่ยงติด 0` — ตรวจครบแล้วแต่รวมยังไม่ถึง 50

## 3.5 บัญชีผู้ใช้และการย้ายเครื่อง

ยืนยันตัวตนได้ 2 ทาง — ฝั่งชีตรับทั้งคู่

| วิธี | เหมาะกับ | ต้องตั้งค่าอะไร |
|---|---|---|
| **บัญชี Google** (แนะนำ) | ใช้หลายเครื่อง / มือถือ | สร้าง OAuth Client ID แล้วใส่ใน `oauth_client_id` |
| **รหัสลับ** | เริ่มต้นเร็ว เครื่องเดียว | ไม่ต้อง (สร้างอัตโนมัติตอนติดตั้ง) |

**เปิดใช้เข้าสู่ระบบด้วย Google**

1. `console.cloud.google.com` → สร้างโปรเจกต์
2. **APIs & Services → OAuth consent screen** → External → ใส่ชื่อแอปกับอีเมล
3. **Credentials → Create credentials → OAuth client ID → Web application**
4. **Authorized JavaScript origins** ใส่ให้ครบทุกที่ที่จะเปิดแอป เช่น
   `http://localhost:5599` และ `https://ชื่อคุณ.github.io`
5. คัดลอก **Client ID** → ใส่ในแท็บ `⚙️ ตั้งค่า` ช่อง `oauth_client_id` → Deploy ใหม่

ให้ครูคนอื่นใช้ร่วมได้โดยใส่อีเมลใน `allowed_emails` (คั่นด้วยจุลภาค) — เว้นว่าง = เฉพาะเจ้าของไฟล์

> Client ID เปิดเผยได้ ไม่ใช่ความลับ · ฝั่ง Apps Script ตรวจ ID token กับ Google ทุกครั้ง (แคชผล 30 นาที)

**ย้ายเครื่องแบบเร็ว** — ⚙️ ตั้งค่า → **📱 ย้ายไปเครื่องอื่น** → คัดลอกลิงก์ไปเปิดบนเครื่องใหม่ ระบบตั้งค่าให้อัตโนมัติ (ลิงก์มีสิทธิ์เข้าถึงข้อมูล อย่าเผยแพร่)

## 3.6 ใช้บนมือถือ

เป็น PWA เต็มรูปแบบ — เปิดเว็บบนมือถือแล้ว

- **Android/Chrome**: เมนู ⋮ → *เพิ่มลงในหน้าจอหลัก* (หรือกดปุ่ม ⬇️ ติดตั้งเป็นแอป ในหน้าตั้งค่า)
- **iPhone/Safari**: ปุ่มแชร์ → *เพิ่มไปยังหน้าจอโฮม*

ไอคอนบนหน้าจอโฮมมาจาก `icons/apple-touch-icon.png` — iOS ไม่อ่านไอคอนใน `manifest.webmanifest`
และไม่รองรับไอคอนแบบ SVG จึงต้องมีไฟล์ PNG นี้แยกไว้ ไม่งั้นจะได้ภาพสกรีนช็อตของหน้าเว็บมาเป็นไอคอนแทน

Service worker เก็บไฟล์แอปไว้ในเครื่อง → เปิดได้แม้ไม่มีเน็ต การเช็คชื่อ/กรอกคะแนนต่อคิวไว้แล้วส่งเมื่อมีสัญญาณ

**ปุ่มย้อนกลับของเครื่องใช้ได้** — แต่ละหน้ามีที่อยู่ของตัวเอง (`#att`, `#work`, …)
กดย้อนกลับแล้วกลับไปหน้าก่อนหน้า ไม่ใช่ออกจากแอป · ส่งลิงก์เจาะจงหน้าให้เพื่อนครูได้
ถ้ามีกล่องโต้ตอบเปิดอยู่ ปุ่มย้อนกลับจะปิดกล่องนั้นก่อน

**มีเวอร์ชันใหม่จะขึ้นแถบให้กดรีเฟรชเอง** ไม่สลับโค้ดใต้มือตอนกำลังกรอกคะแนนอยู่

### การเข้าถึง

- กล่องโต้ตอบปิดด้วย `Esc` ได้ · กด `Tab` วนอยู่ในกล่อง ไม่หลุดไปปุ่มด้านหลัง · ปิดแล้วโฟกัสกลับที่ปุ่มเดิม
- ข้อความยืนยันมุมจอประกาศผ่านโปรแกรมอ่านหน้าจอ (`aria-live`)
- สีสถานะ มา/สาย/ลา/ขาด มีตัวอักษรกำกับเสมอ เพราะคู่ มา↔สาย ยังห่างไม่พอสำหรับคนตาบอดสี
  (ดูตัวเลขที่วัดไว้หัวไฟล์ `styles.css`)

## 4. การใช้งานประจำวัน

| งาน | ทำยังไง |
|---|---|
| เช็คชื่อ | แท็บ 🕐 → เลือกวันที่ (‹ › เลื่อนวัน) → กด **✓ ทุกคนมา** แล้วแตะแก้เฉพาะคนที่ผิดปกติ |
| วันที่สอนหลายคาบ | กด **+ เพิ่มคาบ** ใส่เลขคาบเท่าไหร่ก็ได้ ไม่จำกัด 10 |
| สั่งงาน / เช็คส่งงาน | แท็บ 📝 → เลือกถัง → **+ เพิ่ม** (ใส่รายละเอียดงานได้) |
| เช็คการส่ง | ปุ่ม **ส่ง / ช้า / ไม่ส่ง** กดปุ่มเดียวได้คะแนนเลย · จะพิมพ์คะแนนเองก็ได้ · กดปุ่มเดิมซ้ำ = ยกเลิก |
| หักคะแนนส่งช้า | ตั้ง % ในหน้าตั้งค่า (เริ่มต้น 0 = ไม่หัก) ระบบหักให้ตอนกดปุ่ม "ช้า" |
| นำเข้าคะแนนจาก Excel | ในหน้ากรอกคะแนน → **📋 วางจาก Excel** |
| ดูสถิติ / ติดตามรายคน | แท็บ 📈 → **ทั้งห้อง** (สัดส่วนการมาเรียน · การส่งงานรายชิ้น · การกระจายเกรด · รายชื่อที่ต้องติดตาม) หรือ **รายคน** (ค้นหาชื่อ/เลขที่ → เห็นคะแนน 8 ช่อง วันที่ขาด และงานทุกชิ้น) |
| กรอกลง SGS | แท็บ 📊 → **แตะหัวคอลัมน์** เพื่อคัดลอกทั้งช่อง หรือใช้ **⌨️ โหมดกรอก SGS** ทีละคน |
| เขียนสรุปกลับลงชีต | แท็บ 📊 → **💾 บันทึกลงชีต** (หรือเมนู 📗 ในชีต) |
| กดผิด/แก้ทีเดียวทั้งห้องพลาด | ข้อความยืนยันมุมล่างจอมีปุ่ม **เลิกทำ** ให้กดได้ทันที (ย้อนได้เฉพาะรอบเปิดแอปนี้) |

### ออฟไลน์

เช็คชื่อ/กรอกคะแนนได้แม้ไม่มีเน็ต — ข้อมูลเก็บใน localStorage และต่อคิวไว้
พอกลับมาออนไลน์จะส่งเป็น **batch เดียว** อัตโนมัติ (ป้ายบนหัวจอบอกว่าค้างกี่รายการ)

การสร้างห้อง / แก้รายชื่อ ต้องออนไลน์

### สำรองข้อมูล

ไฟล์ Google Sheet ถูกสำเนาทั้งไฟล์อัตโนมัติ **ทุกวันอาทิตย์ตี 3** ไปไว้ในโฟลเดอร์ Drive
เดียวกับไฟล์นี้ ชื่อ `AssignCheck — สำรองข้อมูล` (เก็บ 8 ก้อนล่าสุด ~2 เดือนย้อนหลัง)
ตั้งเองไม่ต้อง ทำงานทันทีที่กดเมนู **📗 AssignCheck → 🚀 ติดตั้ง** ครั้งแรก

อยากสำรองทันทีก่อนแก้อะไรใหญ่ ๆ — เมนู **📗 AssignCheck → 💾 สำรองไฟล์นี้เดี๋ยวนี้**
กู้คืน: เปิดไฟล์สำรองที่ต้องการ → Deploy เป็น Web app ใหม่ (URL เปลี่ยน ต้องอัปเดตในเว็บแอปด้วย)

### วิธี build และปล่อยของ

```bash
node tools/bundle.mjs        # รวม apps-script/*.gs → ALL-IN-ONE.gs
node tools/build-webapp.mjs  # → dist/app.bundle.js + apps-script/Index.html
node tools/build-pages.mjs   # → docs/ (GitHub Pages)
```

`build-webapp.mjs` กับ `build-pages.mjs` จะ **ตรวจก่อน build ทุกครั้ง** ถ้าไม่ผ่านจะไม่เขียนไฟล์ออกมาเลย

| ตรวจอะไร | ถ้าหลุดไปจะเป็นยังไง |
|---|---|
| `tools/check-sw.mjs` — `sw.js` เก็บไฟล์ครบตามที่ `app.js` import ถึงไหม | ขาดไฟล์เดียว แอปเปิดตอนไม่มีเน็ตไม่ขึ้น |
| `tools/check-sw.mjs` — `sw.js` VERSION ตรงกับ `APP_VERSION` ไหม | แคชเก่าไม่ถูกล้าง ครูติดอยู่กับโค้ดเก่าถาวร |
| `test/parity.mjs` — สูตรคะแนน 2 ฝั่งตรงกันไหม | หน้าจอโชว์เกรดหนึ่ง ชีตบันทึกอีกเกรดหนึ่ง |

รันแยกเองก็ได้: `node tools/preflight.mjs`
ตอนแก้ค้างอยู่และยังไม่อยากให้ติด ใส่ `--skip-checks` ได้ (ห้ามใช้ตอนจะ deploy จริง)

**CI อัตโนมัติ** — `.github/workflows/ci.yml` รันตรวจข้างบน + build แล้วเทียบว่า
`dist/`/`docs/` ที่ commit ไว้ตรงกับผล build ล่าสุดไหม ทุกครั้งที่ push (ต้อง push repo นี้
ขึ้น GitHub ก่อนถึงจะเห็นผลรันใน tab **Actions**) กันเคส "แก้โค้ดแล้วลืมรัน build ก่อน commit"

> ⚠️ **ปล่อยเวอร์ชันใหม่ทุกครั้งต้องบวกเลข** ที่ `APP_VERSION` (`js/version.js`)
> และ `VERSION` (`sw.js`) ให้ตรงกัน — ถ้าไม่บวก `app.bundle.js?v=...` จะเหมือนเดิม
> เบราว์เซอร์กับ service worker จะหยิบของเก่ามาใช้ **โค้ดที่แก้จะไม่ถึงเครื่องครู**
> (`check-sw.mjs` กันไว้ให้แล้ว แต่กันได้แค่ 2 เลขนี้ไม่ตรงกัน ไม่ได้กันตอนลืมบวกทั้งคู่)

### ไอคอนและภาพตอนแชร์ลิงก์

ไอคอนทุกไฟล์อยู่ใน `icons/` และสร้างจาก **`icons/icon.svg` ไฟล์เดียว** ตัว A วาดด้วยเส้นล้วน
ไม่ใช้ฟอนต์ จึงออกมาเหมือนกันทุกเครื่อง

```powershell
powershell -ExecutionPolicy Bypass -File tools/make-icons.ps1
```

รันใหม่เฉพาะตอนเปลี่ยนโลโก้หรือสีแบรนด์ — ไฟล์ไหนใครใช้ ดูที่ [`icons/README.md`](icons/README.md)

`build-pages.mjs` คัดลอกโฟลเดอร์นี้ไป `docs/icons/` ให้เอง เพราะทั้งหน้านักเรียน
และฝั่ง Apps Script (`setFaviconUrl` ใน `04_Api.gs`) ดึงไฟล์จาก `docs/`

> **อยากให้แชร์ลิงก์ในไลน์แล้วขึ้นการ์ดมีรูปชัวร์ทุกแอป**
> ตามสเปก `og:image` ควรเป็น URL เต็ม แต่แต่ละคน deploy คนละที่ ในไฟล์จึงใส่ที่อยู่แบบสัมพัทธ์ไว้
> ซึ่งตัวอ่านลิงก์ส่วนใหญ่ต่อ URL ให้เอง ถ้าอยากให้ชัวร์ 100% แก้บรรทัดนี้ใน `index.html`
> เป็นที่อยู่จริงของคุณ
>
> ```html
> <meta property="og:image" content="https://ชื่อคุณ.github.io/assigncheck/icons/og-image.png">
> ```

## 6. แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| `URL ไม่ถูกต้อง หรือ Deploy ยังไม่ได้ตั้ง "Anyone"` | Deployment ตั้ง access ไม่ถูก — แก้แล้วต้องกด **New deployment** ใหม่ (แก้ deployment เดิมบางครั้งไม่มีผล) |
| `รหัสลับไม่ถูกต้อง` | คัดลอกรหัสจากแท็บ 📖 วิธีใช้ ใหม่ ระวังช่องว่างท้าย |
| แก้โค้ด Apps Script แล้วไม่มีผล | ต้อง **Deploy ใหม่** ทุกครั้ง (หรือใช้ Manage deployments → Edit → Version: New) |
| ค้างส่งไม่ลด | เปิดหน้าตั้งค่า → **⟳ ซิงค์เดี๋ยวนี้** แล้วดูข้อความ error |
| คะแนนในแอปกับในชีตไม่ตรง | กด **💾 บันทึกลงชีต** — ชีตจะอัปเดตจากข้อมูลดิบล่าสุด |
