# ไฟล์ดีไซน์ต้นทาง

ระบบสีและหน้าตาทั้งหมดใน [`styles.css`](../styles.css) สร้างจากไฟล์ในโฟลเดอร์นี้
(หัวไฟล์ `styles.css` อ้างชื่อไฟล์นี้ไว้ตรง ๆ)

| ไฟล์ | คืออะไร |
|---|---|
| `AssignCheck 1c - Full.dc.html` | **ตัวหลัก** — ทุกหน้าจอของแอป ทั้งมือถือและ PC เป็นที่มาของสี ระยะ และขนาดตัวอักษรที่ใช้จริง |
| `AssignCheck Redesign.dc.html` | ฉบับร่างก่อนหน้า เก็บไว้เทียบว่าอะไรเปลี่ยนไปบ้าง |

เปิดดูด้วยการดับเบิลคลิกได้เลย ไม่ต้องรันอะไร

## เวลาจะแก้หน้าตา

ไฟล์พวกนี้เป็น **ต้นแบบ ไม่ใช่โค้ดที่รันจริง** — แก้ที่นี่แล้วแอปไม่เปลี่ยนตาม
ต้องไปแก้ `styles.css` เอง

แต่ถ้าเปลี่ยนสีหลักหรือรูปทรงของแบรนด์ ต้องไล่แก้ให้ครบ 3 ที่ ไม่งั้นจะเพี้ยนกันเอง

1. `styles.css` — ตัวแปรสีที่หัวไฟล์
2. `icons/icon.svg` แล้วรัน `npm run icons` — ไอคอนแท็บและไอคอนแอป
3. `index.html` + `js/theme.js` — สีแถบบนของเบราว์เซอร์ (`theme-color`)
