# AssignCheck — ติดตั้งและใช้งาน (แบบ Apps Script อย่างเดียว)

ไม่ต้องมี GitHub · ไม่ต้องมี OAuth Client ID · ไม่ต้องมีรหัสลับ · ไม่ต้องเปิดคอมค้าง
**มีแค่ Google Sheet ไฟล์เดียว แล้วได้ลิงก์ 1 ลิงก์ที่เปิดได้ทุกเครื่อง**

---

## 🔧 ติดตั้ง (ทำครั้งเดียว ~5 นาที)

### 1. วางโค้ด 2 ไฟล์

เปิดชีต → **ส่วนขยาย → Apps Script**

**ไฟล์ที่ 1 — โค้ดหลัก**
คลิกในช่องโค้ด → `Ctrl+A` → วาง **`ALL-IN-ONE.gs`** ทับ

**ไฟล์ที่ 2 — หน้าเว็บ**
กด **+** ข้างคำว่า Files → เลือก **HTML** → ตั้งชื่อว่า `Index` (สะกดแบบนี้เป๊ะ ตัว I ใหญ่)
→ `Ctrl+A` ลบของเดิม → วาง **`Index.html`** ทั้งไฟล์

กด `Ctrl+S` บันทึก

> ⚠️ ชื่อไฟล์ต้องเป็น `Index` เท่านั้น ถ้าตั้งชื่ออื่นจะขึ้น error ตอนเปิดลิงก์

### 2. ติดตั้งโครงสร้างชีต

กลับไปที่ชีต → **รีเฟรชหน้า** → เมนู **📗 AssignCheck → 🚀 ติดตั้ง / ซ่อมแซมโครงสร้าง**

### 3. Deploy

ใน Apps Script → **Deploy → New deployment** → เลือกประเภท **Web app**

| ช่อง | ค่า |
|---|---|
| Execute as | **Me** |
| Who has access | **Anyone with a Google account** |

> ❗ ต้องเป็น **"Anyone with a Google account"** ไม่ใช่ "Anyone"
> เพราะระบบใช้การล็อกอินของ Google เป็นตัวยืนยันว่าเป็นคุณ

กด **Deploy** → อนุญาตสิทธิ์ (Advanced → Go to AssignCheck (unsafe) → Allow) → **คัดลอก Web app URL**

### 4. เสร็จแล้ว

เปิด URL นั้นในเบราว์เซอร์ = ได้แอปเลย

## 📱 ใช้บนมือถือ

เปิด URL เดียวกันบนมือถือ → ล็อกอิน Google → ใช้ได้ทันที

**แปะไว้หน้าจอโฮม** (เปิดง่ายเหมือนแอป)
- **Android/Chrome** — เมนู ⋮ → *เพิ่มลงในหน้าจอหลัก*
- **iPhone/Safari** — ปุ่มแชร์ → *เพิ่มไปยังหน้าจอโฮม*

ในแอปดูลิงก์ได้ที่ ⚙️ → **🔗 ลิงก์เปิดแอป**

## 🟢 ใช้งานประจำวัน

| งาน | ทำยังไง |
|---|---|
| เช็คชื่อ | 🕐 → **✓ เริ่มเช็ค · ทุกคนมา** → แตะแก้เฉพาะคนขาด/สาย |
| วันที่สอนหลายคาบ | **+ เพิ่มคาบ** ใส่เลขคาบเท่าไหร่ก็ได้ |
| สั่งงาน | 📝 → เลือกถัง → **+ เพิ่ม** (ใส่รายละเอียดงานได้) |
| เช็คส่งงาน | 📝 → แตะชื่องาน → กด **ส่ง / ช้า / ไม่ส่ง** |
| ดูสถิติ | 📈 → **ทั้งห้อง** หรือ **รายคน** |
| กรอกลง SGS | 📊 → แตะหัวคอลัมน์เพื่อคัดลอก → วางใน SGS |

ไม่ต้องกดบันทึก ระบบซิงค์ให้เอง

## ⚠️ ข้อจำกัดที่ต้องรู้

**เปิดแอปตอนไม่มีเน็ตไม่ได้** — เพราะหน้าเว็บถูกโหลดมาจาก Google ทุกครั้ง

แต่ถ้า **เปิดแอปค้างไว้แล้ว** สัญญาณหลุดกลางคาบ ยังเช็คชื่อต่อได้ปกติ ข้อมูลต่อคิวไว้แล้วส่งเองเมื่อสัญญาณกลับมา

> 💡 **วิธีเลี่ยง:** เปิดแอปตอนเริ่มคาบ แล้วอย่าปิดหน้าจนเช็คเสร็จ

## 👥 ให้ครูคนอื่นใช้ด้วย

1. แชร์ไฟล์ชีตให้เขา (สิทธิ์ Editor)
2. ใส่อีเมลเขาในแท็บ **⚙️ ตั้งค่า** แถว `allowed_emails` (คั่นด้วยจุลภาค)
3. เปลี่ยน Deploy เป็น **Execute as: User accessing the web app** แล้ว Deploy ใหม่

เว้น `allowed_emails` ว่างไว้ = เฉพาะเจ้าของไฟล์เท่านั้น

## 🩺 เจอปัญหา — เปิด ⚙️ → ตรวจสอบระบบ ก่อนเสมอ

แอปตรวจให้ 9 ข้อพร้อมปุ่มแก้ในตัว

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| `Script function not found: doGet` | ยังไม่ได้ Deploy หรือ Deploy ผิดประเภท → ต้องเป็น Web app |
| หน้าขาว / `No HTML file named Index` | ไฟล์ HTML ตั้งชื่อผิด ต้องเป็น `Index` เป๊ะ |
| `ระบุตัวตนไม่ได้` | Who has access ตั้งเป็น "Anyone" → เปลี่ยนเป็น **Anyone with a Google account** แล้ว Deploy ใหม่ |
| `บัญชี xxx ไม่มีสิทธิ์` | ล็อกอินคนละบัญชีกับเจ้าของชีต → ใส่อีเมลใน `allowed_emails` |
| แถบแดง "โค้ดในชีตเป็นเวอร์ชันเก่า" | วางโค้ดใหม่แล้วยังไม่ได้ Deploy → **Manage deployments → ✏️ → New version** |
| แก้โค้ดแล้วไม่มีอะไรเปลี่ยน | ลืม Deploy ใหม่ (แค่ Ctrl+S ไม่พอ) |

## 🛠 สำหรับคนแก้โค้ด

แก้ที่ `js/` และ `styles.css` เสมอ แล้ว build ใหม่

```bash
node tools/build-webapp.mjs   # รวมเป็น apps-script/Index.html
node tools/bundle.mjs         # รวมเป็น apps-script/ALL-IN-ONE.gs
node test/parity.mjs          # ตรวจว่าสูตรคะแนน 2 ฝั่งตรงกัน
```

**อย่าแก้ `apps-script/Index.html` หรือ `ALL-IN-ONE.gs` โดยตรง** — ไฟล์พวกนี้ถูกสร้างทับทุกครั้งที่ build

ยังใช้แบบ static host (GitHub Pages / `เปิดแอป.bat`) ได้อยู่ โค้ดชุดเดียวกันรองรับทั้ง 2 โหมดโดยตรวจเองว่าถูกเสิร์ฟจากที่ไหน
