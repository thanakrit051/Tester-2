# dev/ — หน้าไว้ดูดีไซน์ ไม่ได้ใช้ตอนใช้งานจริง

ไฟล์ในโฟลเดอร์นี้ **ไม่ถูกนำไป deploy** ทั้ง Apps Script และ GitHub Pages
(`tools/build-webapp.mjs` กับ `tools/build-pages.mjs` ไม่แตะโฟลเดอร์นี้เลย)

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `demo.html` | หน้าครูพร้อมข้อมูลจำลอง 20 คน — ไล่ดูทุกหน้าจอโดยไม่ต้องต่อชีตจริง |
| `demo-student.html` | หน้านักเรียนพร้อมข้อมูลจำลอง |

## วิธีเปิด

```bash
python tools/serve.py 5599
```

(ใช้ `tools/serve.py` แทน `python -m http.server` — ส่ง `Cache-Control: no-cache`
แก้ไฟล์แล้วรีเฟรชเห็นของใหม่ทันที ไม่ติดแคชของเบราว์เซอร์)

แล้วเปิด `http://localhost:5599/dev/demo.html`
เติม `?setup=1` ถ้าอยากดูหน้าติดตั้งครั้งแรก

## ทำไมถึงปลอดภัย

`demo.html` **ไม่เขียนทับ localStorage ของจริง** — มันครอบ
`Storage.prototype` ไว้ให้ค่าที่ขึ้นต้นด้วย `ac.` เก็บอยู่ในหน่วยความจำเท่านั้น
เปิดหน้านี้แล้วปิดไป ลิงก์ชีตกับรหัสลับที่ตั้งไว้ในแอปจริงยังอยู่ครบ

`demo-student.html` **build สร้างให้เอง** จากแม่แบบเดียวกับ `docs/index.html`
(ไม่ย่อไฟล์ อ่านง่าย) แล้วใส่ `student-mock.js` แทน `config.js` — อย่าแก้ไฟล์นี้ตรง ๆ
อยากเปลี่ยนข้อมูลจำลองให้แก้ `student-mock.js` แล้วรัน:

```bash
npm run build
```

## ตัวช่วยวัดความเร็ว

`demo.html` หน่วง fetch ไว้ 450 มิลลิวินาที ให้ใกล้เคียง Apps Script ของจริง
และเปิดตัวแปรไว้ให้ตรวจใน Console

| ตัวแปร | บอกอะไร |
|---|---|
| `window.__calls` | รายการรอบที่ยิงไปเซิร์ฟเวอร์ เช่น `batch[bootstrap+getClass]` |
| `window.__got` | cell ที่เซิร์ฟเวอร์ได้รับจริง — ใช้ยืนยันว่าไม่มีอะไรหายระหว่างซิงค์ |

ตัวอย่างที่ควรได้:

- เปิดแอป (เคยใช้แล้ว) → `__calls` มีรายการเดียว `batch[bootstrap+getClass]`
- กดปุ่มรัว 8 ครั้ง → ยิงรอบเดียว และโฟกัสในช่องคะแนนไม่หลุด
- กดแทรกระหว่างกำลังซิงค์ → `__got` ต้องได้ครบทุกครั้งที่กด
